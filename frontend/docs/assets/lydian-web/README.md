# Ilustrações do guia Lydian Web

21 SVGs próprios de documentação: capa, 19 páginas/visões e mapa de navegação.
São ilustrações funcionais esquemáticas; não são screenshots nem propostas de
substituição do layout do App. Valores e composição são didáticos.

Usados por `LYDIAN_WEB_DOCUMENTATION.html` na raiz. Manter os arquivos nessa pasta
para preservar links, ampliação, download e impressão do documento. Não contêm
credenciais, dados de usuários, scripts ou dependências externas.

Ao atualizar navegação ou recursos, conferir rotas e componentes reais antes de
modificar rótulos, setas ou estados locais/demonstrativos do mapa.
